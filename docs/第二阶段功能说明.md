# 第二阶段功能说明

本阶段直接基于 `ToDo.Razor` 原有 Razor Pages 和 Bootstrap 页面风格开发。

## 功能入口

- `Agent 中心`：注册的 Agent、Agent 执行表单、最近 AI Session。
- `AI Session`：查看模型调用状态、输入输出和失败原因。
- `事件总线`：发布测试事件、查看待处理和已处理事件。
- `红蓝对抗`：创建主题和目标，运行红方、蓝方、裁判多轮对抗。
- `定时任务`：创建、启停、立即执行每日自动日报任务。
- `项目资料`：从项目详情进入，上传资料、自动计算 SHA-256、版本递增、同名内容冲突提示和下载。
- `外部接口`：企业微信、腾讯会议的网关接口和调用记录，目前状态为 `NotConfigured`，不调用真实第三方服务。

## 数据库迁移

新增迁移：`20260719135626_SecondPhaseFeatures`。

启动时会自动执行 `Database.MigrateAsync()`，创建以下表：

- `agent_definitions`
- `ai_sessions`
- `event_bus_messages`
- `red_blue_sessions`、`red_blue_rounds`
- `scheduled_jobs`
- `project_documents`
- `integration_call_records`

如果本机使用 MySQL，先确认服务已启动，并按 `appsettings.json` 配置账号密码。企业微信和腾讯会议的配置占位在 `Integrations` 节点，当前 `Enabled=false`。

## 验收建议

1. 登录后打开 `Agent 中心`，确认能看到五个默认 Agent；发布事件后在 `事件总线` 查看记录状态变化。
2. 创建一条红蓝对抗，进入详情点击运行，确认每一轮保存红方、蓝方和裁判内容。
3. 在项目详情进入 `项目资料`，上传同名不同内容文件，确认版本号递增并出现冲突提示。
4. 在 `定时任务` 创建任务，使用“立即执行”验证日报生成；后台调度器每 30 秒检查到期任务。
5. 在 `外部接口` 页面测试两个接口，确认页面显示“接口已预留”并生成调用记录。
