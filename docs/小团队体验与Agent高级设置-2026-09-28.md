## 本轮修复

1. **写入意图更保守**：不需要、不希望、不允许、不打算等否定表达不再触发对应工具；引用和代码片段不作为操作授权；条件不明确时不直接开放写入。补充“不需要联网搜索”和“不需要存入资料库”等边界。
2. **成员日报历史与生成分开**：归档项目仍可查看、筛选历史；只有活跃项目可新生成。普通成员权限不扩大。归档报告不显示删除按钮，服务端也明确拒绝删除；错误和成功提示在列表展示。
3. **报告分页**：先限定页码与页大小，再查询数据；相同日期增加 ID 排序，避免越界空页和不稳定分页。
4. **失败后可处理**：“待我处理”展示调度器已有的具体阻塞原因，保留旧记录的通用兜底；从“查看原因并调整任务”进入原任务，不另建一套待办状态。
5. **减少导航干扰**：日常展示待我处理、项目、任务、会议、工作报告；顶部铃铛保留消息入口。审批、Agent、红蓝对抗、操作日志及管理员系统页面收拢到“更多功能 / 管理与更多”；进入相应页面时自动展开。待办保留审批记录入口。

## 高级设置没有删除

- Agent 管理 → 高级设置与历史 → 高级设置。
- Agent 工作要求编辑页底部，也可进入“高级设置：模型、工具与交付规则”。
- 保留模型名称、温度、Token、轮数、超时、系统提示词、能力标签、上下文来源、工具权限、审批配置、交付规则、历史版本与可选测试。
- 简化编辑继续只改三个业务字段，不覆盖技术配置。高级设置面向具有现有系统管理员权限的技术人员，不新增角色、不向普通成员开放。
- 高级设置加入版本校验，旧页面不能覆盖更新后的配置；冲突时保留输入。工具最低审核级别、项目和资料授权仍独立执行。
