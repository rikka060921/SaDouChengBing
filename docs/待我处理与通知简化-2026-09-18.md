# 待我处理与通知简化（2026-09-18）

## 目标与范围

待我处理是需要人工介入的清单，不是第二个任务看板；消息中心是事件历史，不是另一套业务状态。
保留项目权限、审批资格、原有独立审批规则和处理记录，不自动通过敏感操作。
本轮修改与上一轮 Agent 轻量创建、自动执行/验收修改共存；未提交、推送或部署。

## 页面现在怎么工作

- 从真实业务状态只读生成待办，不新增待办状态表，也不需要用户额外勾选完成。
- 原有六个技术分类改为统一卡片：重要决策/严重阻塞 → 逾期 → 今天到期 → 其他。每级按截止时间、等待时长和稳定键排序；未设截止时间不优先。
- 相同任务的失败、待验收、会议督办、逾期等信号合并成一张卡，保留不同的处理入口。未关联任务的会议事项按会议合并。独立审批保留独立卡片。
- 卡片显示为什么找你、当前需要处理的原因、截止时间和操作入口。
- 补齐普通人工任务验收、人工返工、会议任务建议待确认、普通人工任务今天到期/逾期入口。
- 权限过滤、合并、统一排序之后分页，每页 30 条，总数是真实卡片总数，不再把每类前 50 条当成全部。
- 所有任务信号先排除已完成、取消、删除、无项目访问权限的任务；失败记录还要求当前仍失败、指派 Agent 一致且为最新工作项。
- 会议督办按当前正式任务状态、当前截止时间重新判断，不依赖过时缓存；暂缓时间和下一检查点未到时不重复列入普通督办。
- Agent 正常执行时不因临近截止时间要求人工确认；等待审批交给真实审批请求处理，不再额外催申请人解锁。
- 审批链接可以精确定位某一申请，避免历史记录上限导致老申请找不到。

## 通知收敛规则

| 场景 | 默认通知对象 |
| --- | --- |
| 人工任务临期、逾期、返工 | 当前执行人；不可用时按创建人、有效管理人员兜底 |
| 任务待验收 | 有资格的指定审核人；无效/已离开项目/不能自审时找管理人员 |
| Agent 重试耗尽失败 | 有效任务创建人优先，并通知一位管理人员关注严重阻塞 |
| 逾期满一天或连续返工等升级 | 原处理人加一位有效管理人员，不群发全部管理员 |
| 敏感操作审批 | 项目负责人优先，随后项目管理员、系统管理员，选择第一位有实际审批资格的人；其他有资格的人仍可在待办查看 |
| 会议任务建议待确认、缺执行条件 | 一位有效项目管理人员 |
| 普通成功、评论/协作进展、个人日报生成 | 保留站内记录，静默归档，不新增未读负担 |

- 临期提醒窗口从未来三个自然日收敛到未来 24 小时。
- 同一任务、同类提醒、同一个人、同一天去重；同一任务关联多个会议行动项也不会因此生成多条同类消息。
- 有已确认会议承诺的任务由会议督办负责提醒，普通任务扫描不再另发一套；两类后台扫描共用已有的数据库租约能力。
- 成功和普通进展记录按已读静默保存。历史消息不批量删除、不批量改写；旧未读消息可自行标记已读。
- 消息中心默认“待关注”，切换“全部记录”仍能看到普通进展；消息按时间倒序，业务轻重缓急在待办页体现。
- 已读不等于业务完成；处理后的旧消息作为历史保留，当前状态以待我处理和任务详情为准。
- 普通 Agent 自动验收完成仍沿用上一轮逻辑：不发“待验收”通知。

## 实现位置

- `ToDo.Domain/PersonalActionService.cs`：权限过滤、收集、合并和排序。
- `ToDo.Domain/AttentionRecipientService.cs`：处理人优先、有效账号/项目关系过滤和管理人员兜底。
- `ToDo.Domain/UserNotificationService.cs`：共享提醒去重、静默记录、24 小时到期扫描。
- `ToDo.Domain/MeetingActionSupervisionService.cs`：保留督办状态/审计，收敛通知并排除失效任务。
- `ToDo.Razor/Pages/ActionCenter`：统一待办和分页。
- `ToDo.Razor/Pages/Notifications`、`Approvals`：消息入口和精确审批定位。
- Agent 队列、任务提交/验收、会议建议通知统一使用收敛后的接收人规则。

没有新增数据库表、列或迁移。提醒与授权规则在后端执行，不靠隐藏按钮保证安全。

## 验收步骤

1. 创建一个普通人工任务并提交验收：指定审核人能在待我处理看到，未获权限的其他成员看不到。
2. 将同一任务关联会议，并使其逾期/执行失败：只出现一张任务卡，包含相关原因和入口；严重阻塞置顶。
3. 完成、取消、删除任务，或换执行者并重新运行：旧失败不应继续作为当前待办。
4. 生成尚未确认写入的会议任务建议：有写入确认权限的管理人员看到会议卡；普通成员不会收到无法处理的确认要求。
5. 执行常规 Agent 工作：后台运行不进入人工清单；无法自动验收才找审核人。
6. 同一会议任务在一天内重复督办：接收人不会因为任务扫描或多个关联行动项收到重复同类提醒。
7. 检查消息中心：重要处理请求进入待关注，日报/普通成功进入全部记录；标记已读不会把业务待办消除。
8. 高风险 Agent 操作由申请人尝试自审：原有独立审批限制仍在，通知应发给有资格的人；用其他普通成员打开精确审批链接不能越权。
