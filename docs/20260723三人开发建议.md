**我负责的核心内容**

1. **08 工作台和系统导航**
   - 登录后进入项目管理。
   - 左侧导航和项目详情二级菜单。
   - 项目概览、任务、项目资料、会议准备、会议纪要。
   - 手机和小窗口适配。
2. **会议准备和会议纪要流程**
   - 上次会议摘要。
   - 上次会议行动项。
   - 全部未完成任务。
   - 逾期和未来3个自然日内到期任务。
   - 新建本次会议纪要。
   - 原文折叠展示。
   - 会议日期手工选择。
   - 创建者、项目管理员、系统管理员永久编辑。
   - 普通成员只读，但普通成员作为创建者时仍可编辑。
   - AI识别出的行动项先进入人工确认，不直接创建任务。
3. **任务、通知和日报**
   - 子任务、评论、日志的页面重组。
   - 人员和 Agent 执行主体显示。
   - 多项目负责人审核规则。
   - 事件通知、到期提醒、逾期提醒、已读未读和一键已读。
   - 日报变更判断和上次成功汇总时间。
   - 无变化时不调用 AI、不生成重复日报。
4. **审批中心**
   - Agent 提交敏感操作建议。
   - 展示目标对象、修改前后内容和操作原因。
   - 项目管理员、系统管理员、任务创建者或审核人审批。
   - 批准后才真正写入业务数据。
   - 保存审批记录和审计日志。
5. **红蓝对抗集成**
   - 主持人读取当前项目任务和授权资料。
   - 自动生成主题、目标和建议轮数。
   - 默认3轮，允许调整为1至5轮。
   - 红方、蓝方、裁判执行。
   - 结果写回任务或项目资料前走审批。
   - Markdown安全渲染和HTML过滤。

**赵珂薇的任务**

负责复杂 Agent 框架，不负责项目资料权限。

交付内容：

- Agent Runtime。
- 多轮执行和最大轮数控制。
- 工具调用接口。
- Agent 上下文管理。
- AI Session 详情页。
- 输入、输出、调用参数和失败原因记录。
- 事件总线事件：开始、工具调用、完成、失败。
- Agent 执行超时、异常和重试处理。
- 独立交付一个 Agent。

建议她独立交付：

```
任务风险审查 Agent
```

它读取当前项目的任务、负责人、截止日期和状态，输出：

- 逾期任务。
- 即将到期任务。
- 长时间未更新任务。
- 负责人负载异常。
- 风险说明和建议。

第一版只读数据并生成分析，不直接修改任务，便于验证复杂 Agent 框架。

验收标准：

- 能调用任务查询工具。
- 能完成至少两轮工具调用。
- 能在 Session 详情中看到完整过程。
- 工具失败时能记录失败原因。
- 未授权工具不能调用。
- 结果可以被红蓝对抗或会议准备页面复用。

**贺楚的任务**

负责项目资料模块，不负责 Agent Runtime。

交付内容：

- 资料分类。
- 项目资料分类管理。
- Agent 对项目资料的读写权限。
- 分类级权限判断。
- 资料读取审计日志。
- 资料写入审批入口。
- 未授权分类访问拦截。
- 独立交付一个简单 Agent。

建议她独立交付：

```
项目资料摘要 Agent
```

它读取授权的“需求与目标”“会议纪要”“技术资料”，生成项目资料摘要草稿。

它可以：

- 自动读取授权分类。
- 生成摘要草稿。
- 建议资料归类。
- 推荐资料之间的关联。

它不能未经审批：

- 新建资料。
- 修改资料。
- 删除资料。
- 改变资料分类。

验收标准：

- Agent 只能读取授权分类。
- 访问未授权分类时被拒绝并记录日志。
- 能根据资料生成摘要。
- 写入资料时生成审批请求。
- 审批通过后才能保存。
- 审计日志记录 Agent、项目、分类、资料和时间。

**Agent权限统一规则**

无需人工审核：

- 读取已授权资料。
- 生成分析结果。
- 生成草稿。
- 新增任务评论。
- 写入 Agent 执行日志。

必须人工审核：

- 新建、修改、归档或删除项目。
- 新建、修改或删除任务。
- 修改任务负责人、状态、审核人或截止时间。
- 创建会议行动项。
- 创建、修改或删除项目资料。
- 正式保存或发布日报。
- 写回红蓝对抗结果。
