# 撒豆成兵正式验收清单

本文用于正式发布前的签字验收。每次生产发布都应保存提交号、执行人、时间、数据库备份位置和本清单结果；记录中不得包含密码、连接串或 API Key。

## 1. 发布前门禁

- [ ] `git status` 干净，发布提交号与计划版本一致。
- [ ] Release 构建、全部自动化测试和 publish 均成功，无编译错误。
- [ ] `dotnet list package --vulnerable --include-transitive` 未发现已知高危依赖。
- [ ] MySQL、`App_Data`、`wwwroot/uploads` 已完成可恢复备份。
- [ ] 已人工审查本次 EF Core 迁移；没有误删表、列、索引或业务数据。
- [ ] 生产环境未启用演示账号，连接串不含 `CHANGE_ME`，网站不使用 MySQL `root`。
- [ ] `AllowedHosts` 只包含正式域名，可信代理只配置实际 HTTPS 网关 IP。
- [ ] 已轮换任何曾通过聊天、截图或非安全渠道传递的账号密码。

## 2. 基础与安全

- [ ] `GET /health/live` 返回 200，`GET /health/ready` 返回 200。
- [ ] 未登录访问业务页面会跳转登录；普通用户无法访问系统管理和外部集成管理页面。
- [ ] 非项目成员无法读取项目、任务、会议、日报、资料或 Agent 会话。
- [ ] 连续 5 次错误密码后账号锁定 15 分钟；同一来源的登录请求还受每分钟 10 次限流。
- [ ] 登录 Cookie 包含 `HttpOnly`、`SameSite=Lax`，生产环境包含 `Secure`。
- [ ] 响应包含 CSP、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 和 `Permissions-Policy`。
- [ ] 生产错误页不显示数据库、文件路径、堆栈、Secret 或第三方原始响应。

## 3. 核心业务

- [ ] 创建项目、添加成员、创建任务组和任务后，列表与详情一致。
- [ ] 创建会议纪要并同步行动项；重复同步不会生成重复正式任务或重复通知。
- [ ] 更新正式任务状态后，来源行动项状态保持一致。
- [ ] 创建日报、上传和下载附件正常；越权下载被拒绝。
- [ ] 操作日志能追踪关键修改且不记录密码、Key 和完整敏感内容。

## 4. Agent 闭环

- [ ] 新建 Agent 只能保存为草稿，不会因为勾选工具或保存配置而直接上线。
- [ ] 修改已发布 Agent 后，版本递增、运行立即停用、旧测试门禁自动撤销。
- [ ] 隔离测试能按正式项目权限读取上下文，但不会执行任何已配置的业务写入工具。
- [ ] 输出缺少验收关键词、出现禁用协议或请求工具调用时测试失败且无法发布。
- [ ] 隔离测试通过后可发布；暂停后不接新任务，重新发布无需改配置时仍沿用当前版本门禁。
- [ ] 用户创建任务时无需指定数字员工，调度器能自动选择 Agent 并展示选择依据和置信度。
- [ ] 低置信度或高风险操作进入人工确认/审批，不会直接执行。
- [ ] 绑定任务的 Agent 尝试评论或修改同项目其他任务时被拒绝，目标任务没有产生任何业务写入。
- [ ] 非系统管理员无法批准本人发起的高风险 Agent 工具申请；另一位项目审批人可以处理。
- [ ] 审批中心能区分“载荷完整”“载荷异常”和“历史未签名”；修改或清空新审批载荷哈希后，通过与执行均被拒绝。
- [ ] Agent 提交超长字段、跨项目负责人、无效状态/优先级或超过 1 MB 的审批载荷时，服务端拒绝或按字段上限安全截断。
- [ ] Agent 工作项从“待执行”进入“执行中”，最终变为“已完成”“待审批”“重试中”“已失败”或“已取消”，不会永久卡住。
- [ ] Agent 能读取被授权的项目、任务、会议和知识片段，并能完成至少一次真实工具调用和结果回写。
- [ ] 工具调用失败会按策略重试；取消能终止模型请求，重启服务后陈旧任务可以恢复。
- [ ] 执行记录包含 Agent、步骤、耗时、尝试次数和结果，但不泄露模型 Key 或敏感上下文。
- [ ] 工作项提交完成时，同一事务生成唯一交付凭证，包含结论、系统证据、脱敏工具影响、风险提示和 64 位 SHA-256。
- [ ] 交付凭证不复制工具原始参数、完整返回、提示词、密码、Key 或未知敏感字段；非项目成员无法直接访问凭证详情。
- [ ] 人工通过/驳回会同步更新凭证并分别形成强正/负表现信号；重复审核不会重复记分。
- [ ] 人工确认或改选调度推荐会形成幂等反馈；后续同类任务的历史表现优先参考近 180 天人工验收，而不是机械完成率。
- [ ] 返工重新交付时，旧待验收凭证标记为“已被新交付替代”，任务详情只突出最新交付。
- [ ] 交付凭证页面可以启动“交付验收 Agent”；它能读取最新凭证和会议承诺并给出建议通过/驳回，但不会修改任务或正式验收状态。
- [ ] 会议督办 Agent 与交付验收 Agent 均已发布、必须关联项目和任务、没有任何业务工具权限；交付验收 Agent 不参与普通任务自动派单。
- [ ] Agent 运行指标能同时显示机械完成率和人工验收通过率；没有人工样本时显示“暂无样本”，不会用机械完成率冒充验收质量。
- [ ] 已确认会议行动项能显示待关联、待补齐、正常、即将到期、逾期、阻塞、完成或取消状态，以及 L1–L3、检查时间和提醒次数。
- [ ] “立即检查督办”只有会议写入审批人可执行；普通成员只能查看自己有权访问项目的督办结果。
- [ ] 同一天重复检查相同状态不会重复通知；逾期跨 1 天/3 天或任务状态改变时会生成新的升级/状态事件。
- [ ] L1 只通知责任链人员，L2/L3 扩展到项目审核与管理人员；无关项目成员和全局无关人员不收到会议内容。
- [ ] `deploy/Test-ToDo-AgentE2E.ps1` 通过并生成不含凭据的 JSON 报告。

## 5. 项目知识库

- [ ] 上传 PDF、DOCX、PPTX、XLSX 和文本样例后，索引状态最终为“已完成”。
- [ ] 解析失败会显示可重试状态；手动重建索引有效，后台失败不会阻塞网站。
- [ ] Agent 只检索当前项目和自身有权访问的分类/文档。
- [ ] 与问题无关的长文档不会挤占全部提示词预算，相关片段会优先进入上下文。
- [ ] 直接访问 `/uploads/projects/...` 返回 404；资料只能经带权限校验的下载处理器获取。
- [ ] 路径穿越、伪造数据库路径和超范围文件不会被读取。

## 6. 自动化与外部集成

- [ ] 同一个事件或定时任务在多实例并发时只被一个实例抢占执行。
- [ ] 进程异常退出后，超过锁超时的事件、定时任务和 Agent 工作项可恢复。
- [ ] 定时任务失败按 5/15/60 分钟退避，不会每 30 秒持续轰炸第三方服务。
- [ ] 未配置完整凭据时，企业微信和腾讯会议保持关闭并给出明确状态。
- [ ] 启用企业微信后，应用消息真实到达目标账号；失败重试不会产生非预期重复消息。
- [ ] 启用腾讯会议后，可创建会议并按选定模式获取转写。
- [ ] 集成审计包含关联号、幂等键、尝试次数、耗时、HTTP 状态和错误分类；收件人、正文、入会地址和密码均已脱敏。

## 7. 发布与恢复

- [ ] `Deploy-ToDo-Iis.ps1` 创建新 Release、保留运行数据、切换 IIS 并通过 `/health/ready`。
- [ ] 人工刷新登录、项目、任务、Agent、资料和集成页面，无 500/503。
- [ ] 重启应用程序池后仍可登录，资料与附件仍可访问，说明 Data Protection Keys 和运行数据已持久化。
- [ ] 在演练环境制造一次就绪检查失败，部署脚本能自动切回上一文件版本。
- [ ] 已确认数据库迁移回滚方案：文件版本回滚不会自动撤销数据库变更，必要时使用发布前备份恢复。
