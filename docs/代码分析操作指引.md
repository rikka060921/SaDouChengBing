# 代码分析操作指引

## 1. 拉取最新代码
使用以下命令拉取develop分支的最新代码：
```bash
git checkout develop
git pull origin develop
```

## 2. 查看提交记录和改动内容
### 2.1 查看提交历史
```bash
git log --pretty=format:"%h - %an, %ad : %s" --date=short
```

### 2.2 查看特定提交的详细信息
```bash
git --no-pager show <commit-hash>
```
其中`<commit-hash>`是从提交历史中获取的提交哈希值。

## 3. 核验提交内容与代码评估
1. 对每个提交使用`git --no-pager show <commit-hash>`查看详细变更
2. 评估代码质量、遵循的编码规范和实现逻辑
3. 检查是否有潜在的bug或性能问题
4. 验证代码是否符合项目需求
5. 将评估结果整理到审查报告中，保存至docs目录：报告应包含代码进度评估、代码质量评估、问题清单和改进建议。

## 4. 查验项目代码状态
1. 检查所有项目文件，识别已完成的功能模块
2. 记录待办事项和未完成的功能
3. 整理代码中标记的TODO注释
4. 评估代码覆盖率和测试情况
